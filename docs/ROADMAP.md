# ZK Music roadmap

## Phase 0 — Foundation
- [x] React + TypeScript shell
- [x] Responsive desktop/mobile UI
- [x] Local microphone capture
- [x] Local beat import/playback
- [x] Real-time EQ + compression chain
- [x] Low / Medium / High / Mobile profiles
- [x] Local take preview and export
- [x] Automated build validation

## Phase 1 — Recording quality
- Timeline editor
- [x] Take waveform previews
- Low-latency take alignment
- WAV/PCM recording path
- [x] WAV export from recorded takes
- [x] Input device selector
- [x] Beat volume and metronome
- [x] Recording peak/clipping meter
- [x] Local studio preferences
- Undo/redo
- [x] Local take persistence via IndexedDB
- [x] Local multi-take library
- Vocal comping

## Phase 2 — Vocal intelligence
- [x] Real-time pitch detection
- [x] Manual key/scale targeting
- Pitch correction / AutoTune engine
- Key detection
- [x] Noise and room analysis
- [x] De-esser, gate, limiter, reverb and delay
- Smart vocal presets based on measurable audio features

## Phase 3 — Production
- Piano roll
- Drum sequencer
- Sampler
- Built-in instruments
- MIDI
- Tempo map
- Stem handling

## Phase 4 — Mastering
- Loudness metering
- True-peak protection
- Reference-track comparison
- Automatic mastering suggestions
- Export WAV / FLAC / MP3 where supported

## Phase 5 — Desktop/mobile product
- Tauri desktop shell
- Signed Windows builds
- Android/iOS prototype
- Crash reporting with privacy controls
- Updater

## Phase 6 — Optional cloud
Cloud remains optional until product traction justifies infrastructure cost.

- Accounts
- Preset sync
- Project backup
- Collaboration
- Sponsor delivery
- Remote AI only for tasks that cannot be done locally
